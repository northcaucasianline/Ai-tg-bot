AiTGAida Anna v7 — изменения

- Добавлена сохраняемая очередь входящих сообщений (global.messageQueue в data/character.json).
- Очередь обрабатывает сообщения последовательно для каждого собеседника.
- Ожидающие сообщения восстанавливаются после повторного запуска Telegram-клиента.
- Добавлены повторные попытки обработки с ограничением до 3 попыток; неуспешные записи помечаются failed.
- Ожидание учитывает периоды offline и повторно проверяет расписание.
- Исправлен приоритет правила душа, чтобы «просыпается, душ...» не классифицировалось только как пробуждение.
- Синтаксис изменённых JS-файлов проверен через node --check.

Важно:
- Полный тест src/test.js не стартовал в среде сборки: зависимости npm не установлены (dotenv отсутствует). Выполните npm install в проекте.
- Если сообщение приходит во время офлайна, очередь хранит текст и обрабатывает его в доступное окно; это не эмулирует Telegram-факт прочтения.
- В случае ошибки отправки Telegram после успешной генерации ответ может быть повторно сгенерирован при повторной обработке; для строгой exactly-once доставки нужен отдельный outbox/idempotency слой.
- Проверьте прокси в telegramClient.js под свою сеть; адрес 127.0.0.1:12334 оставлен как в исходном проекте.
- .env и node_modules не включены в архив.
